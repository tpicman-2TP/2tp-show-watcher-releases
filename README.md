# 2TP Visuals Show Watcher – downloads

Keeps an eye on the LED processors of a show: NovaStar (MCTRL4K, VX, COEX MX / CX / KU, H-Series) and Pixelhue (P10, P20, P20DS, P80, Q8) on one fullscreen screen – green when all is well, red and loud when an input is lost, a cable is pulled or a processor goes offline. Read only: it never changes a setting on your gear. Watch from any phone in the show network. Free – no licence or key.

**Download:** see [Releases](../../releases/latest) – the newest Windows installer (`Show-Watcher-Setup-x.y.z.exe`, Windows 10/11, 64-bit). The macOS version follows.

*Settings → Check for updates* in the app reads this page (only the app version is sent) and offers a newer version when there is one. Nothing is downloaded or installed by itself.
